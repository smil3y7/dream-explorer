In 2013 I started building Dream eXplorer — a desktop application for
recording and analyzing dreams. Not because anyone asked for it, but because
I was looking for a tool that didn't exist yet: something to help me track
patterns across my own dreams, not just log individual entries.

The application grew — Basic and Advanced editions, a coded-tag system,
sleep-cycle analytics. Alongside it, I wrote and taught: workshops, a
ten-week dream incubator program, articles on lucid dreaming techniques.

Then the funding for further development ran out. The technology stayed
where it was — .NET, Windows 7, a desktop app with no successor. I set the
project aside for a few years. Not abandoned — paused.

When AI arrived, part of it came back — in a different shape. Instead of one
application, I'm now building **Sentria**: a modular ecosystem of tools for
exploring dreams and consciousness, connected to one another instead of
standing alone.

This page stays here as the start of that thread — where it began, and
where it led.
